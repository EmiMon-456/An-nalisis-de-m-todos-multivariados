# Implementación de la prueba de Hosmer-Lemeshow
def hosmer_lemeshow(y_true, y_prob, g=10):
    """
    Prueba de bondad de ajuste de Hosmer-Lemeshow.
    y_true: valores observados (0/1)
    y_prob: probabilidades predichas
    g: número de grupos (por defecto 10)
    """
    # Crear DataFrame auxiliar
    df_hl = pd.DataFrame({'y': y_true, 'p': y_prob})
    df_hl['grupo'] = pd.qcut(df_hl['p'], q=g, duplicates='drop')
    
    # Calcular observados y esperados por grupo
    hl_tabla = df_hl.groupby('grupo').agg(
        n=('y', 'size'),
        observados=('y', 'sum'),
        esperados=('p', 'sum'),
        p_medio=('p', 'mean')
    )
    hl_tabla['obs_no'] = hl_tabla['n'] - hl_tabla['observados']
    hl_tabla['esp_no'] = hl_tabla['n'] - hl_tabla['esperados']
    
    # Estadístico HL
    HL = (((hl_tabla['observados'] - hl_tabla['esperados'])**2) /
      (hl_tabla['n'] * hl_tabla['p_medio'] * (1 - hl_tabla['p_medio']))).sum()
    
    gl = len(hl_tabla) - 2
    p_valor = 1 - stats.chi2.cdf(HL, gl)
    
    return HL, gl, p_valor, hl_tabla

HL, gl, p_valor, tabla = hosmer_lemeshow(y_sm, y_pred_prob, g=10)

print(f"Grados de libertad: {gl}")

# Pseudo R²
ll_modelo = modelo_logit.llf        # log-verosimilitud del modelo completo
ll_nulo = modelo_logit.llnull       # log-verosimilitud del modelo nulo
n = len(y_sm)

# McFadden
r2_mcfadden = 1 - (ll_modelo / ll_nulo)

# Cox-Snell
r2_coxsnell = 1 - np.exp((2 / n) * (ll_nulo - ll_modelo))

# Nagelkerke (ajusta Cox-Snell para que el máximo sea 1)
r2_nagelkerke = r2_coxsnell / (1 - np.exp((2 / n) * ll_nulo))

print("=== PSEUDO R² ===\n")
print(f"Log-verosimilitud modelo completo: {ll_modelo:.4f}")
print(f"Log-verosimilitud modelo nulo:     {ll_nulo:.4f}\n")
print(f"McFadden:    {r2_mcfadden:.4f}")
print(f"Cox-Snell:   {r2_coxsnell:.4f}")
print(f"Nagelkerke:  {r2_nagelkerke:.4f}")

Interpretación de resultados (Vinos: clase 0 vs. resto)¶

Exploración. Los vinos de clase 0 tienen en promedio más alcohol ($13.75$ vs. $12.63$) y más fenoles totales ($2.84$ vs. $2.03$). Las correlaciones entre predictores son bajas (la mayor es $-0.34$), así que no hay multicolinealidad preocupante.

Odds Ratios.

  • alcohol ($OR = 20.94$, $IC 95\%: 6.63-66.14$, $p < 0.001$): por cada unidad adicional de alcohol, los odds de que el vino sea clase $0$ se multiplican por $~21$, manteniendo lo demás constante.
  • total_phenols ($OR = 27.97$, $IC 95\%: 6.60-118.51$, $p < 0.001$): efecto positivo y significativo, con un intervalo muy amplio (estimación poco precisa).
  • malic_acid ($OR = 0.81$, $p = 0.487$) y ash ($OR = 2.65$, $p = 0.346$) no son significativas: sus intervalos incluyen el $1$.

Evaluación. Accuracy de $0.899$ y AUC de $0.969$, lo que indica muy buena capacidad de discriminación. La matriz de confusión muestra $9$ falsos positivos y $9$ falsos negativos de $178$ vinos. Hosmer-Lemeshow (p = 0.556 > 0.05) no rechaza $H_0$, por lo que no hay evidencia de falta de ajuste. McFadden $= 0.660$, Cox-Snell $= 0.568$ y Nagelkerke $= 0.789$ indican un ajuste muy bueno.

Comparación con sklearn. En el conjunto de prueba el modelo obtuvo accuracy de $0.833$ y AUC de $0.926$, menores que en statsmodels ($0.899$ y $0.969$). Es esperable: statsmodels se evaluó con los mismos datos con los que se ajustó, mientras que sklearn se evalúa en datos no vistos, que es una medida más realista. La prueba tiene solo $54$ vinos, así que la estimación es variable.

Conclusión. El alcohol y los fenoles totales son los predictores relevantes. Se podría simplificar el modelo quitando malic_acid y ash.
